# Security Policy

## Supported Versions

Security fixes land on `main` and in the next tagged `1.x` release.

## Reporting a Vulnerability

Please **do not** open a public issue for suspected vulnerabilities in disguised-executable filtering, safety-gate enforcement, or SQL/GraphQL parameter handling.

Report privately via **GitHub Private Vulnerability Reporting** on this repository:
<https://github.com/spencernorton/Armiger-Connectors/security/advisories/new>

Include a minimal synthetic reproducer and the affected commit hash. You can expect an initial response within 7 days.
